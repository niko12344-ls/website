# 关于本站

Liang Wiki 存放自己写的维基

## 内容原则

- 尽量使用 Markdown，保持内容可迁移。
- 按主题组织目录，不把所有内容堆在首页。
- 重要操作记录前提、步骤和结果。
- 不在公开文档中存放密码、令牌、私钥或其他敏感信息。
- 本维基为个人整理，内容仅供参考，不保证完整、准确或持续更新。
- 引用外部内容时注明来源、作者、访问日期和许可证；有许可证的按许可证署名并标明是否修改，许可证不明或不允许转载的只链接不复制。

## 维护方式

直接在 GitHub 仓库中新增或编辑 `.md` 文件，提交后由 Cloudflare Pages 自动构建。
