# Markdown 写作方法

## 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
```

## 强调与链接

**粗体**、*斜体*、`行内代码`。

## 提示块

::: tip 提示
用于补充说明。
:::

::: warning 注意
用于提醒风险或注意事项。
:::

::: danger 危险
用于重要警告。
:::

## 图片

把图片放进 `docs/public/images/`，然后引用：

```markdown
![图片说明](/images/example.png)
```
